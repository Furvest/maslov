# Маслов · личный архив

Одностраничный сайт-архив о поэте, педагоге и просветителе Маслове. Сделан как
PHP-страница с заглушками под тексты, фотографии, видео и аудио. Внешних
библиотек и шрифтов нет — страница работает офлайн.

## Как посмотреть

**Быстрый способ (без PHP).** Откройте `preview.html` двойным щелчком. Это
статическая копия страницы: вся вёрстка, анимации и интерактив работают, но
данные не пересобираются из PHP.

**Полный способ (PHP 8+).** Из папки проекта выполните:

```bash
php -S localhost:8000 -t .
```

и откройте <http://localhost:8000/>. Можно также положить папку в XAMPP/OpenServer
и открыть `index.php` через локальный сервер.

В Windows есть `start.bat`: если PHP найден в PATH, он поднимет сервер, иначе
откроет `preview.html`.

> На этой машине PHP не был установлен. Для проверки использовался портативный
> PHP 8.3; в поставку он не входит.

## Что внутри

Пять блоков:

1. **Обзор** — имя, краткий текст, портрет, мини-ролик и медиатека с вкладками
   «Фото / Видео / Документы».
2. **Биография** — разворот книги с двумя страницами, буквицей, заметками на
   полях, таймлайном и архивными вклейками. Развороты листаются стрелками, точками
   и свайпом.
3. **Творческий путь** — архив с фильтрами (рукописи / видео / события), карточки
   открываются в модальных окнах; ниже — интерактивная презентация из трёх
   стихотворений в трёх формах:
   - «Печатная машинка» — текст печатается на глазах;
   - «Караоке» — строки подсвечиваются по таймеру;
   - «Созвездие» — стихотворение собирается из слов.
4. **Просветительский путь** — аудиогид от первого лица (4 главы) и культурная
   карта с кликабельными точками и маршрутом.
5. **Обращение потомкам** — постер мини-фильма, послание, сгенерированное ИИ, и
   кнопка копирования текста.

Мини-фильм — это CSS-анимация из шести сцен (37 секунд) с финальным посланием.
Это не видеофайл, а «оживший раскадровщик»: его можно заменить настоящим MP4.

## Где менять контент

Все данные собраны в начале `index.php`:

| Переменная | Что это |
|---|---|
| `$site` | имя, годы, город, лид, цитата |
| `$photos` | фотографии: путь, подпись, код |
| `$videos` | видео: постер, путь к MP4, длительность |
| `$archive` | карточки архива: рукописи, видео, документы |
| `$poems` | три стихотворения для интерактивной презентации |
| `$chapters` | главы аудиогида |
| `$mapPoints` | точки культурной карты и привязка к главам |
| `$bioSpreads` | тексты и вклейки разворотов книги |
| `$aiMessage` | послание потомкам |

Тексты с квадратными скобками (`[город]`, `[год]`) — явные места для ваших
данных. Это художественные заглушки, а не проверенные факты.

### Фото

Замените файлы в `assets/img/`, сохранив имена:

- `photo-01.jpg` — портрет 4:5 (герой);
- `photo-02.jpg … photo-06.jpg` — 4:3 (медиатека);
- `book-inside.jpg` — вклейка в книге;
- `archive-doc.jpg` — скан документа;
- `film-poster.jpg` — постер блока «Обращение»;
- `mini-film.jpg` — картинка мини-ролика в первом экране;
- `video-01.jpg … video-05.jpg` — постеры видео 16:9.

Можно менять и пути в массивах. Главное — сохранять пропорции, иначе `object-fit`
обрежет кадр.

### Видео

Положите MP4 в `assets/video/` с такими именами:

```
maslov-reading.mp4
diploma.mp4
reading-by-students.mp4
roundtable.mp4
message.mp4
```

PHP проверяет наличие файла: если видео найдено, в модальном окне появится
настоящий плеер, если нет — аккуратная заглушка с постером.

### Аудио

Ожидаемые файлы:

```
assets/audio/maslov-reading.mp3
assets/audio/poem-karaoke.mp3
assets/audio/guide-01.mp3 … guide-04.mp3
```

Пока файлов нет, интерфейс показывает заглушку и подсказку. Голос в аудиогиде
задуман как синтезированный; при замене на реальную запись обновите подписи.

### Режим заглушек

Кнопка **«Заглушки»** в шапке подсвечивает все 39 мест, которые нужно заменить, и
показывает пути к файлам. Режим запоминается в `localStorage`. Это удобно для
передачи проекта редактору.

## Структура

```
maslov/
├── index.php              # страница и все данные
├── preview.html           # статическая копия для просмотра без PHP
├── start.bat              # запуск сервера или превью в Windows
├── README.md
└── assets/
    ├── css/style.css
    ├── js/app.js
    ├── img/               # постеры и заглушки
    ├── video/             # сюда кладутся MP4
    └── audio/             # сюда кладутся MP3
```

## Технические детали

- PHP 8+ без фреймворков и базы данных.
- Адаптивность: 1440 / 1024 / 820 / 640 / 380 px.
- Клавиатура: Escape закрывает модальные окна; стрелки листают фото; фокус
  удерживается внутри диалога.
- Учитывается `prefers-reduced-motion`: анимации отключаются.
- Проверено в Edge (Chromium) 156: ошибок в консоли нет, горизонтальной
  прокрутки нет.

## Важно про ИИ

Послание потомкам и подписи «сгенерировано ИИ» — демонстрационные. Текст написан
языковой моделью и не является реальной цитатой Маслова. Перед публикацией
проверьте факты, даты и получите разрешение на использование фотографий и видео.
