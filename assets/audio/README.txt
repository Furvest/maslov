# Аудио

Положите сюда MP3 с такими именами:

- maslov-reading.mp3 — чтение стихотворения «Тишина»;
- poem-karaoke.mp3 — дорожка для режима «Караоке»;
- guide-01.mp3 … guide-04.mp3 — главы аудиогида.

Пока файлов нет, страница показывает заглушку и подсказку.
Голос в аудиогиде задуман как синтезированный (ИИ), а не как реальная запись.
